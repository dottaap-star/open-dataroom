# Code of conduct

This project is maintained as a small open-source effort. The rules here are short and unambiguous; if you want a more formal document, swap this file for the [Contributor Covenant](https://www.contributor-covenant.org/) — both are fine, neither is a substitute for acting in good faith.

## What we expect

Be useful, be respectful, assume good intent until you have specific reason not to. Disagreements about technical direction are welcome; ad-hominem attacks, harassment, doxxing, and discrimination of any kind are not.

When you file an issue or PR, describe the problem clearly and stick to the topic. When you review someone else's work, be specific and kind. When you maintain or triage, be transparent about decisions.

## What gets you removed

- Personal attacks, harassment, or sustained disruption of project communication.
- Posting other contributors' personal information without consent.
- Discrimination or slurs targeting any protected class.
- Deliberate code submissions that introduce security holes, backdoors, or telemetry without disclosure.

Maintainers may, at their discretion, edit or delete comments, close issues or PRs, or ban contributors from the project. We try to escalate gradually (a quiet word → a public warning → a temporary block → a permanent ban) but reserve the right to skip steps for egregious behaviour.

## Reporting

Report violations to the maintainer email listed in [SECURITY.md](SECURITY.md). Reports stay confidential. We respond within seven days. Retaliation against reporters is itself a violation.

## Scope

This applies to issue trackers, pull requests, discussions, and any other project space. It applies to maintainers, contributors, and one-time visitors alike.
